# Financial-Sales-Analysis
# 📊 Financial Sales Analysis Dashboard

## 📌 Project Overview

This is an end-to-end Data Analytics project where I analyzed a financial sales dataset using Python, MySQL, and Power BI.

The project demonstrates the complete analytics workflow from data cleaning to dashboard creation.

**Workflow:**

Raw Dataset → Python → MySQL → Power BI Dashboard

---

# 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- MySQL
- Power BI

---

# 📂 Project Workflow

### 1️⃣ Data Cleaning (Python)

Performed the following preprocessing steps:

- Removed duplicate records
- Cleaned column names
- Converted currency values into numeric format
- Exported the cleaned dataset

---

### 2️⃣ Data Analysis (MySQL)

Performed business analysis including:

- Total Sales
- Total Profit
- Average Profit
- Total Units Sold
- Country-wise Analysis
- Product-wise Analysis
- Segment-wise Analysis
- Monthly Sales Trend
- Top 5 Products
- Loss-making Transactions

---

### 3️⃣ Dashboard (Power BI)

Created an interactive dashboard including:

- KPI Cards
- Sales by Country
- Product-wise Profit
- Segment-wise Analysis
- Monthly Sales Trend
- Interactive Filters
